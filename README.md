# 深廣 通販画面の導線デモ

公開URL: https://ss4gdev.github.io/fukahiro-shop-demo/

店舗の公開通販を参考にしたレビュー用の静的デモです。注文・決済や個人情報入力は実装していません。本番通販とは別のデモで、表示する商品情報は制作時の参考情報です。

各商品のARボタンから、別の公開サイト https://ss4gdev.github.io/fukahiro-ar-demo/ へ移動します。「通販で購入する」は元の通販商品ページへの通常リンクです。

商品画像・ロゴは深廣の既存通販を参考にしています。これらの素材を再利用する権利を配布するものではありません。
